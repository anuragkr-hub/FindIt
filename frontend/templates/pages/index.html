How FindIt Deterministic Matching Works

Unlike vague keyword searches, FindIt evaluates compatible Lost and Found reports with strict, calibrated scoring criteria.

30%

Category

Exact match across categorized campus item types, with partial points for related tech/accessories.

20%

Color

Normalized token matching. If either report omits a color, 0 points are awarded without false inflation.

20%

Location

Campus landmark and building token overlap (e.g. Science Library, Student Union, Gym).

15%

Date Proximity

Same day = 15 pts, within 3 days = 12 pts, decreasing with calendar distance.

15%

Description

Stopword-filtered token set similarity (brands, serial patterns, stickers, unique features).
